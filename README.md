# Todo App

A simple yet powerful to-do list application with local storage functionality.

## Features

✅ **Add Tasks** - Quickly add new tasks to your list
✅ **Mark Complete** - Check off completed tasks
✅ **Delete Tasks** - Remove tasks you no longer need
✅ **Local Storage** - Your tasks are saved in your browser's local storage
✅ **Statistics** - See total and completed task counts
✅ **Responsive Design** - Works on desktop, tablet, and mobile
✅ **Clean UI** - Modern and intuitive interface

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add" or press Enter
4. Check the checkbox to mark tasks as complete
5. Click "Delete" to remove a task
6. Click "Clear Completed" to remove all completed tasks

## Technology Stack

- **HTML5** - Structure
- **CSS3** - Styling with flexbox and gradients
- **JavaScript (ES6)** - Functionality with local storage API

## Local Storage

Your tasks are automatically saved to your browser's local storage. This means:
- Tasks persist even after closing the browser
- No server required
- Works offline
- Data is stored locally on your device

## Browser Compatibility

- Chrome/Edge (Latest)
- Firefox (Latest)
- Safari (Latest)
- Opera (Latest)

## Installation

Simply download the files and open `index.html` in your browser. No installation required!
